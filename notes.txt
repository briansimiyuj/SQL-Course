We need to download MySQL, go to mysql.com/downloads and download the MySQL Community Server
Once the installer is downloaded, run it and follow the instructions to install MySQL
    1. Choose Custom Setup Type 
    2. Choose the MySQL Server 

Once the MySQL Server is installed, we need to start the MySQL Server. Run the following command as an administrator:
    `C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -u root -p`

Then put in the password for the root user

You should see:
    mysql> ${ MySQL command will go here }
